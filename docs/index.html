      The font

      Hibur Mono keeps Amharic letters from overlapping. The installer adds it.

      Terminal settings
      Ghostty font-codepoint-map = U+1200-U+139F,U+2D80-U+2DDF,U+AB00-U+AB2F=Hibur Mono
      kitty symbol_map U+1200-U+139F,U+2D80-U+2DDF,U+AB00-U+AB2F Hibur Mono
      iTerm2 Settings › Profiles › Text › Use a different font for non-ASCII text › Hibur Mono
      Windows Terminal Settings › your profile › Appearance › Font face: Cascadia Mono, Hibur Mono
      macOS Terminal The installer adds a Bible profile. Open it with Shell › New Window › Bible.
